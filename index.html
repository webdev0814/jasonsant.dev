01 / 06

Browser LLM debate orchestrator

Inspect repository: browser-llm-debate-orchestrator

Problem

Comparing model reasoning manually makes synthesis inconsistent and difficult to repeat.

Architecture

A browser-based coordinator selects participants and structures a multi-model debate across supported providers.

Governance

Explicit participant selection and staged outputs keep model contributions visible for human review.

Impact

Demonstrates a repeatable pattern for comparing competing model responses before a person accepts a conclusion.

02 / 06

Stakeholder outreach draft generator

Inspect repository: stakeholder-outreach-draft-generator

Problem

Directory cleanup, domain checks, spreadsheet coordination, and draft preparation create repetitive outreach work.

Architecture

A staged workflow cleans directory data, checks DNS MX records, synchronizes sheets, and creates throttled Gmail drafts.

Governance

Draft creation preserves a human approval boundary; throttling and validation reduce uncontrolled outbound activity.

Impact

Shows how multiple validation and preparation steps can become one reviewable workflow without auto-sending messages.

03 / 06

Agent prompt context compression

Inspect repository: agent-prompt-context-compression

Problem

Long agent instructions consume context and make reusable operational guidance harder to maintain.

Architecture

Reusable instruction patterns compress prompt context while retaining constraints, priorities, and execution guidance.

Governance

Preserved rules and explicit correctness boundaries keep compression from becoming uncontrolled omission.

Impact

Provides an inspectable method for making agent instructions more compact and portable across systems.

04 / 06

Agent VPS security hardening

Inspect repository: agent-vps-security-hardening

Problem

Independent agent hosts expand operational exposure when baseline server controls are inconsistent.

Architecture

A hardening protocol organizes host protections for VPS-based AI agent deployments.

Governance

Documented controls make security expectations reviewable, repeatable, and suitable for change tracking.

Impact

Turns host-security knowledge into an actionable deployment reference for independent agent infrastructure.

05 / 06

Single-VM agent consolidation

Inspect repository: single-vm-agent-consolidation

Problem

Running separate agent stacks can add infrastructure and operating complexity to constrained environments.

Architecture

A deployment guide consolidates Hermes Agent and OpenClaw on one Oracle Always Free VM.

Governance

Sequenced migration, service separation, verification, and rollback-aware guidance reduce avoidable transition risk.

Impact

Documents a practical consolidation path that operators can inspect and adapt to a resource-constrained host.

OpenClaw to Hermes orchestrator migration

Architecture

Governance

Impact
